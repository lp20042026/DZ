# Финансовая модель пекарни

Автономная HTML-страница финансовой модели с интерактивным обзором, ОПиУ, ДДС, анализом чувствительности и аналитической запиской.

## Запуск

Откройте `index.html` в современном браузере. Сборка и сервер не требуются. Для загрузки шрифта Inter требуется подключение к интернету; без него используется системный шрифт.

Параметры модели сохраняются только в локальном хранилище браузера пользователя.

## Данные модели

Расчёты и исходные значения параметров встроены в клиентский HTML-код. В публичном репозитории они доступны всем посетителям. Страница не подключается к Google Sheets и не отправляет параметры модели на сервер.
